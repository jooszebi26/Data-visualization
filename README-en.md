# 💼 Jobs Dashboard – Power BI

## 📘 Introduction
The goal of this project was to create a **clean and easy-to-understand Power BI dashboard** that analyzes **job posting data** from multiple perspectives.

The focus was on achieving a **minimalist design**, **structured data presentation**, and implementing a **drill-through feature** to ensure the analysis is both aesthetically pleasing and functional.

## 🧠 Skills Acquired During the Project
- 🔹 **Power BI Dashboard Design** – creating a clean and well-structured layout using shapes  
- 🔹 **Power Query** – data cleaning, type conversion, and preprocessing  
- 🔹 **DAX Fundamentals** – creating calculated measures and KPIs  
- 🔹 **Drill-through Pages** – building interactive, multi-view reports  
- 🔹 **Data Visualization Principles** – designing dashboards that are informative yet minimalistic  
- 🔹 **Data Modeling & Type Management** – setting accurate data types (numeric, date, text, currency)

---

## 🏁 Conclusion
This project represents a **comprehensive yet minimalist Power BI report** that highlights trends and patterns in job postings data.  
Through this work, I learned how to visually present data in a way that is both **insightful and visually appealing**.
